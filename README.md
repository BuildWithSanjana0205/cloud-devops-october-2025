# 🚀 AWS DevOps & Cloud Learning Journey

This repository documents my hands-on learning journey through a **Linux, Cloud, DevOps & Python** course that started on **25 August 2025**.  
While the full course covers Linux, Python, and DevOps tooling as well, **this repo focuses only on the AWS part** for now.

I use it to store:
- **Daily logs** – what I learned, which concepts, and which practical I did each day  
- **Concepts** – short notes on AWS topics (commands, diagrams, pitfalls)  
- **Labs** – course practicals and mini-projects on AWS  

📅 Course Start: 28 April 2026  
📍 Focus (this repo): AWS services and DevOps workflows around AWS  

> Goal: Learn by building, document clearly, and keep everything reproducible.

---

## 🧭 How I'm Using This Repo

- **Daily Logs:** One file per day (`daily-logs/YYYY-MM-DD.md`) describing:
  - What I learned
  - Which AWS concepts were covered
  - Which practical/lab I did
- **Concepts:** Topic-wise notes in `concepts/` (e.g., EC2, VPC, ALB, S3, IAM).
- **Labs:** Step-by-step course practicals in `labs/` with READMEs so I can re-run them later.

This is a **learning journal**, not a polished product. It shows my day-to-day progress, mistakes, and fixes.

- **Storage & Database:** S3, EBS, RDS (MySQL)

## 📝 Daily Log Template

Each day I create a new file: `daily-logs/YYYY-MM-DD.md`.

```markdown
# YYYY-MM-DD

## What I Learned Today
- Bullet points of key learnings (in my own words)

## Concepts Covered
- AWS services / concepts touched (e.g., EC2, ALB, Target Group, Security Groups)
- Any new commands (AWS CLI / console steps / scripts)

## Practical / Lab Done
- Lab name + link to `labs/` folder
- Short description of what I implemented

## Issues / Errors & How I Fixed Them
- Mistakes, error messages, and fixes (or open doubts)

## Links & References
- AWS docs, videos, articles, or any helpful resources

## Tomorrow's Focus
- 2–3 things I plan to learn or practice next
```
